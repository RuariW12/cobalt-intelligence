# Screenshots

The README links to four images from this directory. Replace them and they
appear automatically:

| file | what to capture |
| --- | --- |
| `home.png` | the index, showing every section |
| `commodities.png` | a section page with prices, a chart and headlines |
| `summary.png` | the daily summary panel with a generated summary in it |
| `day-mode.png` | any page with the sun/moon toggle switched to day |
